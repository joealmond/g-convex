# Original Features (g-matrix)

> Reference document for original g-matrix feature set

## Core Features

### Vibe Check Matrix
- Safety vs Taste scatter plot
- Price vs Taste (Value mode)
- Quadrant labels: Holy Grail, Survivor Food, Russian Roulette, The Bin

### Voting System
- Safety: Clean / Sketchy / Wrecked
- Taste: Yass / Meh / Pass
- Price: 1-5 dollar signs
- Store tagging (predefined + custom)
- GPS location tagging

### Gamification
- Scout Points with bonuses
- 6 Achievement badges
- Daily voting streaks
- Profile page with stats

### AI Features
- Image-based product recognition
- Gluten-free risk assessment
- Ingredient analysis

### Admin
- Product management
- Vote deletion
- Batch recalculation
- View as user mode

### i18n
- English (EN)
- Hungarian (HU)

## Technology Stack (Original)

- Next.js 14 (App Router)
- Firebase Auth + Firestore
- Genkit for AI
- next-intl for i18n
- recharts for visualization
- shadcn/ui components
